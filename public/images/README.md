# Image Open Graph

Vous devez créer une image `og-image.jpg` dans ce dossier pour le SEO.

## Spécifications recommandées :
- Dimensions : 1200x630 pixels
- Format : JPG ou PNG
- Poids : < 300KB
- Contenu : Votre nom "Bryan Thierry" + votre titre "Webdesigner & Développeur Front-End"
- Design : Utilisez votre identité visuelle (couleurs de votre portfolio)

Cette image apparaîtra quand votre site sera partagé sur :
- Facebook
- Twitter/X
- LinkedIn
- WhatsApp
- etc.

Pour créer l'image, vous pouvez utiliser :
- Canva
- Figma
- Photoshop
- Ou tout autre outil de design

Placez le fichier final ici : `/public/images/og-image.jpg`
