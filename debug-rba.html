Wordpress

Réseau Biodiversité pour les Abeilles (RBA) est une association engagée pour la cohabitation entre agriculture et biodiversité. Face au déclin des pollinisateurs, nous avons mené avec mon équipe une refonte complète de leur identité visuelle.

Notre mission a été de repenser la stratégie de communication, de créer une nouvelle identité forte, puis de développer le site sur WordPress. J'ai utilisé Illustrator pour concevoir un nouveau logo centré sur l'abeille, puis Figma pour modéliser l'interface.

Pour redonner du sens à leur image, nous avons misé sur une palette de couleurs cohérente : L'orange, pour la vitalité et le lien direct avec le miel, le noir, pour la lisibilité, le blanc, pour la clarté et une déclinaison de violet, apportant une touche d'élégance selon les supports.

Résultat ? Un logo symbolique, accompagné d'un site web aligné avec les valeurs du RBA. Ce projet est conçu pour sensibiliser autour d'un enjeu vital : la protection des pollinisateurs.
