# 🚀 DÉPLOIEMENT VERCEL - SOLUTION DÉFINITIVE

## ÉTAPES SIMPLES (5 MINUTES MAX) :

### 1. Aller sur Vercel
- https://vercel.com/
- Se connecter avec GitHub

### 2. Importer votre projet
- Cliquer "Add New" → "Project"
- Chercher "site_portfolio2.0"
- Cliquer "Import"

### 3. Configuration automatique
Vercel détectera automatiquement :
- ✅ Framework : Astro
- ✅ Build Command : `npm run build`
- ✅ Output Directory : `dist`

### 4. Variables d'environnement
Ajouter dans Vercel :
- `POCKETBASE_URL` = `https://pocketbase-portfolio-production.up.railway.app`

### 5. Déployer
- Cliquer "Deploy"
- Attendre 2-3 minutes
